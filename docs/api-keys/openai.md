# OpenAI API key (realtime-translate)

OpenAI `gpt-realtime-translate`: speech-to-speech translation with transcript text. ≈ $2.04/h.

## 1. Create an account

Sign in or sign up at [platform.openai.com](https://platform.openai.com). (A ChatGPT subscription does **not** include API usage.)

## 2. Add credit — required

The API is prepaid.

1. Open **Billing** ([link](https://platform.openai.com/account/billing)) → **Add payment details**.
2. Choose a first purchase (minimum $5).
3. Auto-reload is on by default; turn it off or set a monthly recharge limit if you want a hard cap.

Purchased credits expire after one year.

## 3. Create a key

1. Open **API keys** ([link](https://platform.openai.com/api-keys)) → **Create new secret key**.
2. Name it `Subveil`, keep the default project → **Create**.
3. **Copy it now** — OpenAI shows the full key only once. Lost it? Create a new one.

## 4. Paste it into Subveil

**Models & Providers → OpenAI gpt-realtime-translate → API key** → paste → **Save**. Then pick it as the engine.

## Good to know

- When credits hit zero the balance can briefly go negative before requests stop.
- Deleting a key takes effect within seconds.
