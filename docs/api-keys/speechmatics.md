# Speechmatics API key

Speechmatics real-time: transcription with up to five translation targets. $0.30–0.80/h + $0.65/h translation.

## 1. Create an account

Sign up at [portal.speechmatics.com/signup](https://portal.speechmatics.com/signup). New accounts get **$100 credit**
(valid 12 months), no card required.

## 2. Create a key

1. Sign in to the [Speechmatics Portal](https://portal.speechmatics.com).
2. Go to **Settings → API Keys** ([link](https://portal.speechmatics.com/settings/api-keys/)).
3. Enter a name (e.g. `Subveil`) → generate → **copy it right away**.

## 3. Add a card (when the credit runs out)

On the free tier the API stops when credits are used up. To continue: **Workspace → Billing → Payment method →
Add payment card** (needs the Admin role). That upgrades you to Pro: credits are used first, then the card is charged monthly.

## 4. Paste it into Subveil

**Models & Providers → Speechmatics → API key** → paste → **Save**. Then pick Speechmatics as the engine.

## Good to know

- The free tier allows 2 real-time sessions at a time — enough for Subveil's System + Mic streams.
- Real-time audio is not stored unless you opt in to model training.
