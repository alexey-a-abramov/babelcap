# AssemblyAI API key

> **The AssemblyAI adapter is not built yet.** You can save a key now; it will be used once the adapter ships.

AssemblyAI Streaming: real-time transcription (no translation). $0.30–0.45/h.

## 1. Create an account

Sign up at [assemblyai.com/dashboard/signup](https://www.assemblyai.com/dashboard/signup). New accounts get **$50 credit**, no card required.

## 2. Copy the key

Your key is on the [dashboard home page](https://www.assemblyai.com/dashboard/home). Copy it.

## 3. Paying

After the free credit you pay as you go — add a card in the dashboard's billing section.

## 4. Paste it into Babelcap

**Models & Providers → AssemblyAI Streaming → API key** → paste → **Save**.

## Good to know

- Streaming is billed by **how long the connection is open**, not by audio sent.
- The free tier can start 5 new streams per minute; pay-as-you-go 100.
